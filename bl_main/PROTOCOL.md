# Bootloader协议文档

## 概述
本文档描述了基于Modbus的简化型引导加载程序协议，用于通过会话状态机制更新主MCU及其从MCU的固件。该协议使用标准Modbus RTU功能码0x04进行寄存器读取，并使用自定义功能码0x65-0x69进行引导加载程序操作。通过引入会话状态机制，擦除、编程、复位等操作变为通用的，根据当前会话状态自动操作本地MCU或指定的从MCU。超时管理统一由上位机实现，不需要协议层处理。

### 地址映射
引导加载程序使用直接地址空间来管理本地和远程闪存操作：

#### 地址空间布局
| 地址范围 | 描述 |
|---------|------|
| 0x080000-0x087FFF | 主MCU引导加载程序（受保护） |
| 0x088000-0x0BFFFF | 主MCU APP (48KB) - 本地闪存 |
| 0x000000-0x03FFFF | 从MCU1 APP (256KB) - 远程闪存 |
| 0x000000-0x03FFFF | 从MCU2 APP (256KB) - 远程闪存 |

#### 会话机制
通过会话状态机制确定操作的目标设备：
- 当会话目标为本地MCU时，使用本地MCU地址空间 (0x088000-0x0BFFFF)
- 当会话目标为从MCU时，使用从MCU地址空间 (0x000000-0x03FFFF)

## 功能码

### 标准功能码
| 功能码 | 名称 | 描述 |
|-------|------|------|
| 0x04 | 读输入寄存器 | 读取引导加载程序信息寄存器 |

### 引导加载程序功能码
| 功能码 | 名称 | 描述 |
|-------|------|------|
| 0x65 | 进入引导加载程序模式 | 切换到引导加载程序模式 |
| 0x66 | 擦除闪存 | 按地址范围擦除闪存内存（根据会话状态操作本地或从MCU） |
| 0x67 | 写入闪存 | 将数据写入闪存内存（根据会话状态操作本地或从MCU） |
| 0x68 | 刷新FLASH缓存 | 将FLASH缓冲区全部写入FLASH（根据会话状态操作本地或从MCU） |
| 0x69 | 跳转到应用程序 | 跳转到应用程序代码（根据会话状态操作本地或从MCU） |
| 0x6A | 完成APP写入 | 完成APP写入操作并更新app_info信息（根据会话状态操作本地或从MCU） |

### 会话管理功能码
| 功能码 | 名称 | 描述 |
|-------|------|------|
| 0x70 | 设置会话目标 | 设置当前会话操作目标（本地MCU或指定从MCU） |
| 0x74 | 查询会话状态 | 查询当前会话状态和目标设备 |
| 0x75 | 重置设备 | 重置当前会话目标设备 |

## 功能细节

### 功能码0x04 - 读输入寄存器
从寄存器读取引导加载程序信息。

**请求**：
```
[从站地址][0x04][起始地址高位][起始地址低位][寄存器计数高位][寄存器计数低位][CRC低位][CRC高位]
```

**响应**：
```
[从站地址][0x04][字节计数][数据...][CRC低位][CRC高位]
```

### 功能码0x65 - 进入引导加载程序模式
将设备切换到引导加载程序模式。

**请求**：
```
[从站地址][0x65][CRC低位][CRC高位]
```

**响应**：
```
[从站地址][0x65][状态][CRC低位][CRC高位]
```

状态：
- 0x00 = 成功
- 0xFF = 失败

### 功能码0x66 - 擦除闪存
按指定地址范围擦除闪存内存。

**请求**：
```
[从站地址][0x66][起始地址(4字节)][长度(4字节)][CRC低位][CRC高位]
```

特殊命令：起始地址=0xFFFFFFFF，长度=0xFFFFFFFF 擦除整个APP区域

**响应**：
```
[从站地址][0x66][状态][实际起始地址(4字节)][实际长度(4字节)][CRC低位][CRC高位]
```

状态：
- 0x00 = 成功
- 0x02 = 地址超出范围
- 0x03 = 擦除失败
- 0xFF = 未知错误

### 功能码0x67 - 写入闪存
将数据写入指定地址的闪存内存。

**请求**：
```
[从站地址][0x67][地址(4字节)][长度高位][长度低位][数据...][CRC低位][CRC高位]
```

**响应**：
```
[从站地址][0x67][状态][已写字节数高位][已写字节数低位][CRC低位][CRC高位]
```

状态：
- 0x00 = 成功
- 0x02 = 地址超出范围
- 0x04 = 写入失败
- 0x05 = 地址未对齐
- 0xFF = 未知错误

### 功能码0x68 - 刷新FLASH缓存
将FLASH缓冲区全部写入FLASH。

**请求**：
```
[从站地址][0x68][CRC低位][CRC高位]
```

**响应**：
```
[从站地址][0x68][状态][CRC低位][CRC高位]
```

状态：
- 0x00 = 成功
- 0x04 = 写入失败
- 0xFF = 未知错误

### 功能码0x69 - 跳转到应用程序
跳转到指定地址的应用程序代码。

**请求**：
```
[从站地址][0x69][跳转地址(4字节)][CRC低位][CRC高位]
```

跳转地址：应用程序入口地址 (0xFFFFFFFF = 默认地址)

**响应**：
```
[从站地址][0x69][状态][CRC低位][CRC高位]
```

状态：
- 0x00 = 成功
- 0x01 = 无效应用程序
- 0xFF = 未知错误

### 功能码0x70 - 设置会话目标
设置当前会话操作目标（本地MCU或指定从MCU）。

**请求**：
```
[从站地址][0x70][目标类型][目标地址高位][目标地址低位][CRC低位][CRC高位]
```

参数：
- 目标类型：0x00 = 本地MCU，0x01 = 从MCU
- 目标地址：从MCU地址 (0x0000 = 本地MCU)

**响应**：
```
[从站地址][0x70][状态][CRC低位][CRC高位]
```

状态：
- 0x00 = 成功
- 0x01 = 无效目标类型
- 0x02 = 无效目标地址
- 0xFF = 未知错误

### 功能码0x74 - 查询会话状态
查询当前会话状态和目标设备。

**请求**：
```
[从站地址][0x74][CRC低位][CRC高位]
```

**响应**：
```
[从站地址][0x74][状态][目标类型][目标地址高位][目标地址低位][CRC低位][CRC高位]
```

参数：
- 状态：0x00 = 成功，0xFF = 未知错误
- 目标类型：0x00 = 本地MCU，0x01 = 从MCU
- 目标地址：从MCU地址 (0x0000 = 本地MCU)

### 功能码0x75 - 重置设备
重置当前会话目标设备。

**请求**：
```
[从站地址][0x75][重置类型][延迟高位][延迟低位][CRC低位][CRC高位]
```

参数：
- 重置类型：0x00 = 软件重置，0x01 = 硬件重置
- 延迟：重置前延迟时间（毫秒）

**响应**：
```
[从站地址][0x75][状态][CRC低位][CRC高位]
```

状态：
- 0x00 = 成功
- 0xFF = 未知错误

### 功能码0x76 - 完成FLASH写入
完成FLASH写入操作并更新app_info信息。

**请求**：
```
[从站地址][0x76][主版本号][次版本号][构建版本高位][构建版本低位][应用长度(4字节)][CRC32值(4字节)][时间戳(4字节)][CRC低位][CRC高位]
```

参数：
- 主版本号：应用程序主版本号
- 次版本号：应用程序次版本号
- 构建版本：应用程序构建版本号
- 应用长度：应用程序实际长度（字节）
- CRC32值：应用程序CRC32校验码
- 时间戳：应用程序构建时间戳

**响应**：
```
[从站地址][0x76][状态][CRC低位][CRC高位]
```

状态：
- 0x00 = 成功
- 0x01 = 无效参数
- 0x02 = 写入失败
- 0xFF = 未知错误

## 寄存器映射

### 0xF000-0xF00F: 引导加载程序核心信息
| 地址 | 名称 | 类型 | 描述 |
|-----|------|------|------|
| 0xF000 | BL_MAGIC | uint16 | 引导加载程序魔数 (0xBEEF = 引导加载程序模式) |
| 0xF001 | BL_VERSION | uint16 | 引导加载程序版本（高位字节=主版本，低位字节=次版本） |
| 0xF002 | BL_STATE | uint16 | 引导加载程序状态 |
| 0xF003 | BL_CAPABILITY | uint16 | 能力位图 |
| 0xF004 | BL_ERROR_CODE | uint16 | 最后错误代码 |

### 0xF100-0xF10F: 闪存信息
| 地址 | 名称 | 类型 | 描述 |
|-----|------|------|------|
| 0xF100-0xF101 | FLASH_SIZE | uint32 | 闪存总大小（字节） |
| 0xF102-0xF103 | FLASH_APP_START | uint32 | 应用程序起始地址 |
| 0xF106 | FLASH_WRITE_BLOCK_SIZE | uint16 | 闪存写入块大小 |
| 0xF107 | FLASH_WRITE_ALIGN | uint16 | 闪存写入对齐要求 |

### 0xF200-0xF20F: 会话状态信息
| 地址 | 名称 | 类型 | 描述 |
|-----|------|------|------|
| 0xF200 | SESSION_TARGET_TYPE | uint16 | 会话目标类型 (0=本地MCU, 1=从MCU) |
| 0xF201-0xF202 | SESSION_TARGET_ADDR | uint32 | 会话目标地址 (0x00000000 = 本地MCU) |
| 0xF203 | SESSION_STATE | uint16 | 会话状态 (0=空闲，1=操作中) |

### 0xF300-0xF30F: 应用程序信息
| 地址 | 名称 | 类型 | 描述 |
|-----|------|------|------|
| 0xF300 | APP_INFO_VALID | uint16 | app_info结构体有效标志 (0=无效, 1=有效) |
| 0xF301 | APP_MAGIC_HIGH | uint16 | app_info魔数高位 (0xDEAD) |
| 0xF302 | APP_MAGIC_LOW | uint16 | app_info魔数低位 (0xBEEF) |
| 0xF303 | APP_MAJOR_VERSION | uint16 | 应用程序主版本号 |
| 0xF304 | APP_MINOR_VERSION | uint16 | 应用程序次版本号 |
| 0xF305 | APP_BUILD_VERSION_HIGH | uint16 | 应用程序构建版本号高位 |
| 0xF306 | APP_BUILD_VERSION_LOW | uint16 | 应用程序构建版本号低位 |
| 0xF307-0xF308 | APP_LENGTH | uint32 | 应用程序实际长度（字节） |
| 0xF309-0xF30A | APP_CRC32 | uint32 | 应用程序CRC32校验码 |
| 0xF30B-0xF30C | APP_TIMESTAMP | uint32 | 应用程序构建时间戳 |
| 0xF30D | APP_VALID_FLAG | uint16 | 应用程序有效标志位 (0x00AA = 有效) |

**验证规则说明：**
- **app_info结构体有效性**：通过magic number (0xDEADBEEF) 验证，APP_INFO_VALID寄存器反映此状态
- **应用程序有效性**：通过valid_flag (0xAA) 验证，表示应用程序本身是否有效
- 两个标志位独立验证，分别指示不同层面的有效性

## 更新流程

### 本地MCU更新
1. 设置会话目标：发送功能码0x70，目标类型=0x00（本地MCU）
2. 进入引导加载程序模式：发送功能码0x65
3. 擦除闪存：发送功能码0x66，地址=0xFFFFFFFF擦除整个APP区域
4. 写入固件：发送功能码0x67，以数据块形式发送固件数据
5. 验证固件：发送功能码0x68，使用CRC32验证
6. 跳转到应用程序：发送功能码0x69，地址=0xFFFFFFFF

### 从MCU更新
1. 设置会话目标：发送功能码0x70，目标类型=0x01（从MCU），指定从MCU地址
2. 命令从MCU进入引导加载程序：发送功能码0x65
3. 擦除从MCU闪存：发送功能码0x66，使用从MCU地址范围
4. 写入从MCU固件：发送功能码0x67，使用从MCU地址范围
5. 验证从MCU固件：发送功能码0x68，使用从MCU地址范围
6. 命令从MCU跳转到应用程序：发送功能码0x69，地址=0xFFFFFFFF（或使用默认地址0xFFFFFFFF）
